# ai-brain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ai-brain`, an always-on emergent household agent (brain + 4 expert loops) on the Gemini free tier with markdown memory, a quota ledger, a provider chain, allowlisted tools, Slack-agent I/O, and ✅-gated world actions.

**Architecture:** One Python 3.13 asyncio container. `AgentLoop` instances (brain, energy, health, house-ops, researcher) share a `Ledger` and a `ProviderChain`, each owning a `MemoryDir` under `/memory`. Loops communicate only through inbox markdown notes. `slack_io` is a thin Bolt Socket Mode adapter; `approvals` turns `propose()` into outbox files executed on a ✅ reaction.

**Tech Stack:** Python 3.13, `uv`, `httpx`, `slack-bolt` (async, socket mode), `pytest` + `pytest-asyncio` + `respx`, Docker (arm64), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-06-ai-brain-design.md`

## Global Constraints

- Python `>=3.13`, dependencies pinned exactly (`==`), managed with `uv` (`uv.lock` committed; CI runs `uv lock --check`).
- Package name `ai_brain`, source in `ai-brain/src/ai_brain/`, tests in `ai-brain/tests/`. Run tests with `cd ai-brain && uv run pytest -q`.
- No tool ever raises to the model: tool functions return a JSON string, errors as `{"error": "..."}`.
- Tools take **names**, never paths. Memory file names must match `^[a-z0-9][a-z0-9_.-]{0,63}$`.
- Model default chain: `gemini:gemini-3.8-flash,gemini:gemini-3.5-flash-lite`.
- Daily quota resets at midnight `America/Los_Angeles`.
- Brain priority: experts may only spend while the bucket's remaining daily requests **and** tokens are both > 40%.
- Hard caps: 8 tool rounds per cycle, 60 s per model call, 20 Slack posts per hour, Sonos quiet hours 22:00–07:00 `Europe/Stockholm`, 24 h proposal timeout.
- Only the brain may use Slack tools and `propose`. Experts may not.
- Secrets only via env; no tool exposes env.
- Every commit: `git commit -m "feat(ai-brain): ..." -m "Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>"`. No `$()`, no heredocs in commit commands.
- Do not exercise the Sonos executor against a real speaker in any test. `DRY_RUN=1` in every non-unit run.

### Task 2: Quota ledger

**Files:** Create `ai-brain/src/ai_brain/ledger.py`; Test `ai-brain/tests/test_ledger.py`

**Interfaces:**
```python
@dataclass(frozen=True) class Limits: rpm: int; tpm: int; rpd: int
@dataclass(frozen=True) class Decision: allowed: bool; retry_at: float | None; reason: str
Priority = Literal["brain", "expert"]
class Ledger:
    def __init__(self, limits: dict[str, Limits], path: Path, clock: Callable[[], float] = time.time)
    def can_spend(self, key: str, priority: Priority, est_tokens: int = 4000) -> Decision
    def record(self, key: str, prompt_tokens: int, completion_tokens: int) -> None
    def record_429(self, key: str, retry_after_s: float | None) -> None
    def record_not_found(self, key: str) -> None      # disabled 24h
    def record_ok(self, key: str) -> None             # resets consecutive_429
    def remaining_fraction(self, key: str) -> tuple[float, float]  # (requests, tokens) of RPD/ daily-token budget
    def next_available_at(self, priority: Priority) -> float | None  # earliest retry across keys
    def keys(self) -> list[str]
    def snapshot(self) -> dict                        # for metrics
```
Daily token budget = `tpm * 60 * 24 / 10` (a conservative cap; free tier has no daily token limit, but experts must starve before the brain, so a synthetic day budget gives `remaining_fraction` meaning). Day key: `datetime.fromtimestamp(clock(), ZoneInfo("America/Los_Angeles")).date()`. Persist JSON `{"day": "...", "buckets": {key: {...}}}` after every mutation via tmp+replace. On load, if JSON is invalid or `day` mismatches: start fresh; if invalid (not merely stale) set each bucket's `requests_day = rpd // 2` and `tokens_day = daily_tokens // 2`.

### Task 3: LLM types, ProviderChain, FakeProvider

**Files:** Create `ai-brain/src/ai_brain/llm/__init__.py`, `ai-brain/src/ai_brain/llm/fake.py`; Test `ai-brain/tests/test_chain.py`

**Interfaces:**
```python
@dataclass(frozen=True) class ToolSpec: name: str; description: str; parameters: dict   # JSON schema
@dataclass(frozen=True) class ToolCall: id: str; name: str; args: dict
@dataclass(frozen=True) class Message:
    role: Literal["system","user","assistant","tool"]; content: str = ""
    tool_calls: tuple[ToolCall, ...] = (); tool_call_id: str = ""; name: str = ""
@dataclass(frozen=True) class Usage: prompt_tokens: int; completion_tokens: int
@dataclass(frozen=True) class Reply: text: str; tool_calls: tuple[ToolCall, ...]; usage: Usage; model: str
class ProviderError(Exception):
    kind: Literal["not_found","rate_limited","server","timeout","bad_request"]; retry_after_s: float | None
class Provider(ABC):
    key: str                                    # "gemini:gemini-3.8-flash"
    async def complete(self, messages: list[Message], tools: list[ToolSpec], max_tokens: int) -> Reply
class ChainExhausted(Exception): retry_at: float | None
class ProviderChain:
    def __init__(self, providers: list[Provider], ledger: Ledger, clock=time.time)
    async def complete(self, messages, tools, max_tokens, priority: Priority) -> Reply
    @staticmethod def from_settings(settings, ledger) -> ProviderChain   # parses "gemini:<model>" entries; unknown prefix -> ValueError
class FakeProvider(Provider):   # llm/fake.py
    def __init__(self, key: str, script: list[Reply | ProviderError])   # pops in order; raises if exhausted
    calls: list[tuple[list[Message], list[ToolSpec]]]
```
Chain algorithm per spec table: for each provider in order: `ledger.can_spend(key, priority)` false → skip (remember earliest retry_at); try `complete`; on success `ledger.record`+`record_ok`; `not_found` → `record_not_found`, next; `rate_limited` → `record_429(retry_after)`, next; `server`/`timeout` → retry same once, then next; `bad_request` → raise immediately (a bug, not a quota issue). If none succeed raise `ChainExhausted(retry_at=min retry)`.

### Task 4: GeminiProvider

**Files:** Create `ai-brain/src/ai_brain/llm/gemini.py`; Test `ai-brain/tests/test_gemini.py` (respx)

**Interfaces:** `GeminiProvider(model: str, api_key: str, client: httpx.AsyncClient | None = None, timeout_s: float = 60)`, `key = f"gemini:{model}"`.

Mapping to `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent` (header `x-goog-api-key`):
- `system` message → `systemInstruction.parts[0].text`.
- `user` → `contents[] {role:"user", parts:[{text}]}`; `assistant` with tool_calls → `{role:"model", parts:[{functionCall:{name,args}}...]}` plus `{text}` if content; `tool` → `{role:"user", parts:[{functionResponse:{name, response:{"result": <json-parsed content or {"text": content}>}}}]}`.
- tools → `tools:[{functionDeclarations:[{name,description,parameters}]}]`.
- `generationConfig: {maxOutputTokens, temperature: 0.7}`.
- Response: concatenate `parts[].text`; each `parts[].functionCall` → `ToolCall(id=f"call_{n}", name, args)`. `usageMetadata.promptTokenCount/candidatesTokenCount` (missing → 0).
- Errors: 404 → `not_found`; 429 → `rate_limited` with `retry_after_s` parsed from `error.details[].retryDelay` like `"12s"` or `Retry-After` header; 400 → `bad_request`; 5xx → `server`; `httpx.TimeoutException` → `timeout`.

```python
    extras: dict[str, Any] = field(default_factory=dict)            # approvals, slack_out, http client

    def specs_for(self, loop: str) -> list[ToolSpec]

def ok(data: Any) -> str      # json.dumps({"ok": true, ...}) helper
def err(msg: str) -> str
```

### Task 9: AgentLoop

**Files:** Create `loop.py`; Test `tests/test_loop.py`

**Interfaces:**
```python
@dataclass class CycleResult: status: Literal["ok","no_budget","error","timeout","paused"]; model: str; rounds: int; next_wake_s: int
class AgentLoop:
    def __init__(self, name, memory: MemoryDir, chain: ProviderChain, registry: ToolRegistry, ctx: ToolContext, heartbeat_s: int, priority: Priority, constitution: str, clock, pause_file: Path, max_rounds=8, call_timeout_s=60)
    wake: asyncio.Event
    async def run_cycle(self) -> CycleResult
    async def run_forever(self) -> None       # loop: wait(min(heartbeat, next_wake) or wake event) → run_cycle → sleep
    last_cycle: CycleResult | None; last_cycle_at: float
```
`run_cycle`:
1. If `pause_file.exists()` → `paused`, next wake = heartbeat.
2. notes = `memory.unread_notes()`; system message = `memory.read_context(constitution)` + a fixed instruction block: "You are running one think cycle. Use tools. End by calling end_cycle." If `memory.needs_compaction()` add: "Your memory is large: merge related facts, delete outdated ones by overwriting, and prune." (Deletion = overwriting a fact with `deleted` is acceptable in v1.)
3. Up to `max_rounds`: `chain.complete(messages, registry.specs_for(name), 4000, priority)` under `asyncio.wait_for(..., call_timeout_s)`; append assistant message; for each tool call dispatch and append tool message; stop when no tool calls or `end_cycle` was called.
4. `ChainExhausted` → status `no_budget`, next wake = `retry_at - now` (min 60). Timeout → `timeout`. Any other exception → `error` (log traceback), next wake = heartbeat.
5. Always: `memory.append_journal(f"[{status}] model={model} rounds={n} {summary}")`, `memory.mark_done(notes)`, `memory.purge_done()`.
6. next wake = clamp(`end_cycle` minutes*60, heartbeat/2, 12h) if set else heartbeat.
Before each cycle post Slack status `processing` for any topic mentioned this cycle is out of scope; instead `slack_out.set_status` is called by `slack_post` itself (Task 8 sets `processing` on post and `active` after the cycle via `ctx.extras["cycle_topics"]`, which the loop clears at end of cycle and flips to `active`).
